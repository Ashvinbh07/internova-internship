## How to Run the Student Management System

1. Clone this repository:

   ```bash
   git clone https://github.com/Ashvinbh07/internova-internship.git
   ```

2. Open the cloned folder in Visual Studio Code.

3. Navigate to the Week 1 Student Management System Python file.

4. Run the file using Python:

   ```bash
   python filename.py
   ```

   Replace `filename.py` with the actual Python filename.
