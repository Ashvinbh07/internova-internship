### Task 10 -- Mini Data Analysis Project

## Sales Data Analysis Project

A practical sales analytics project using a large and intentionally
messy sales dataset.

### Dataset

-   Approximately 15,000 cleaned sales records.
-   18 columns containing customer, product, sales, profit, region,
    order, and payment information.
-   Dataset includes missing values, duplicate records, inconsistent
    text values, and invalid numerical values for cleaning practice.

### Data Analysis Workflow

1.  Load the sales dataset.
2.  Inspect the dataset structure and statistics.
3.  Identify and handle missing values.
4.  Remove duplicate records.
5.  Standardize inconsistent text values.
6.  Correct invalid quantity and discount values.
7.  Select and filter records.
8.  Sort sales and profit data.
9.  Perform NumPy statistical analysis.
10. Perform GroupBy analysis.
11. Create Pivot Tables.
12. Extract useful business insights.
13. Export the cleaned dataset.

### GroupBy Analysis

The project analyzes sales and profit by:

-   Product category
-   Region
-   Customer segment
-   Product
-   Month

### Pivot Table Analysis

Created Pivot Tables for:

-   Sales by Category and Region
-   Sales by Customer Segment and Category
-   Sales by Region and Order Status
